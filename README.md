## Features
- Goal creation, tracking, and completion (Firestore CRUD)
- Coin/reward system tied to goal progress
- Virtual pet with unlockable items
- Email/password authentication with forgot-password
- Light/dark theme support

## Tech Stack
- React Native (Expo, Expo Router)
- TypeScript
- Firebase / Firestore
- NativeWind
- Zustand
